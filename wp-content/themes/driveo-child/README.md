# Driveo Child

One-page luxury chauffeur site built on **Hello Elementor + Elementor (Free)**.
No extra plugins, no animation libraries: vanilla JS and CSS.

## Set up on a fresh WordPress

```bash
wp theme install hello-elementor
wp plugin install elementor --activate
wp theme activate driveo-child
php wp-content/themes/driveo-child/tools/build-template.php   # only if you edited the builder
wp driveo install          # media, Elementor kit, menu, page, front page
wp elementor flush-css
```

`wp driveo install` is safe to re-run: media is reused, and the page is rebuilt from
`templates/driveo-home.json`. **Re-running overwrites edits made in Elementor**, so run
`wp driveo export` first if the page has been edited.

## Where things live

| Concern | Location |
|---|---|
| Page structure and content | Elementor (page "Home", Canvas template). Seed: `templates/driveo-home.json`, generated by `tools/build-template.php` |
| Global colours and fonts | Elementor → Site Settings (set by the installer) |
| Breakpoints | Elementor → Site Settings → Layout: mobile 639, mobile extra 767, tablet 1023 |
| Visual design | `assets/css/driveo.css` (tokens, components, responsive, a11y) |
| Interactions | `assets/js/driveo.js` |
| Nav links | Appearance → Menus → "One-page navigation" |
| Quote form (fields, labels, mail, messages) | Contact Form 7 → Contact Forms → "Quote request" (seed: `templates/cf7-quote-form.txt`) |
| Quote form rules (validation, spam, reference) | `inc/quote-form.php` (CF7 hooks) |
| Quote requests storage | Not stored — CF7 only emails. Install Flamingo to keep copies in WP Admin |
| Driveo Elementor widgets | `inc/elementor-widgets.php` |
| Render helpers, shortcodes | `inc/shortcodes.php` |

### CSS class hooks

Every styled Elementor element has a `dx-*` class under **Advanced → CSS Classes**.
Change layout (columns per breakpoint, order) in Elementor; change look in `driveo.css`.

## Editing content (no code needed)

| Content | Where the admin edits it |
|---|---|
| Logo (header, hero, quote seal, footer) | **Appearance → Customize → Site Identity → Logo** — one upload updates all four. Each "Driveo Logo" widget can instead use its own image (Elementor panel → Image: Custom) |
| All headings, paragraphs, labels, captions, city/service/process/testimonial copy, footer text | Elementor → Home → the Heading / Text Editor widget |
| Buttons (label, link, `data-vehicle` for Fleet) | Elementor → Button widget (Link → ⚙ Custom attributes) |
| Fleet images and alt text | Elementor → Image widget (alt text: Media Library) |
| Hero video (desktop, phone), poster, depth-rail words, pause/play labels | Elementor → **Driveo Hero Media** widget (Media Library pickers) |
| WhatsApp and social links, their accessible names | Elementor → **Driveo Social Links** widget (repeater) |
| Header navigation labels and targets | Appearance → Menus → "One-page navigation" |
| Nav landmark name / mobile "Menu" label, install-button label | Elementor → Shortcode widget attributes |
| Quote form fields, options, labels, hints, buttons, success panel, messages (incl. theme validation messages), mail | Contact Form 7 → Contact Forms → "Quote request" |
| Phone, email | Elementor → footer "Contact" Text Editor (the icons are added by CSS to `tel:` / `mailto:` links) |

**Stays in code on purpose:** layout, styling and animation; section IDs and CSS classes;
per-vehicle passenger/luggage limits and the "Hourly hire" rule (`inc/quote-form.php`); the
"Skip to content" accessibility link; decorative planes, orbit rings and arrow glyphs.

**Commands that overwrite admin edits:** `wp driveo install` rebuilds the Home page from
`templates/driveo-home.json` (run `wp driveo export` first to keep Elementor edits);
`wp driveo cf7 --force` replaces the CF7 form. `wp driveo install` never changes an existing
CF7 form or an existing Site Identity logo.

## Quote form

Contact Form 7 is the form manager: one form, "Quote request", embedded in the Elementor
Quote section with `[contact-form-7 id="…" html_class="dx-quote-form"]`.

* The CF7 form is the **single source of truth** for City, Service, Vehicle and Hours options.
  Edit them in the CF7 editor only; CF7 rejects any other value on the server.
* `wp driveo install` creates the form only if it is missing. `wp driveo cf7 --force`
  overwrites the live form with `templates/cf7-quote-form.txt` (loses CF7-editor changes).
  The form ID is stored in the `driveo_quote_form_id` option.
* `wp driveo check` lists the live options and reports rules that no longer match them
  (the "Hourly hire" service, per-vehicle limits, Fleet "Quote this car" buttons). The same
  warnings appear to administrators on the Dashboard and the Contact Forms screen.
* Field names: `client-name`, `client-email`, `client-phone`, `city`, `journey-type`,
  `vehicle`, `pickup`, `destination`, `hours`, `pickup-date`, `pickup-time` (theme-provided
  `[time]` tag), `passengers`, `luggage`, `notes`.
* Server-side rules added through CF7 hooks (`inc/quote-form.php`): Destination required
  unless "Hourly hire"; Hours (2–16) required for "Hourly hire"; Business Van 7 passengers /
  8 bags, all other vehicles 4 / 3. CF7 itself rejects values that are not select options.
* Spam: honeypot field `dx-website` and 5 submissions / 10 min per IP, via `wpcf7_spam`.
* Reference: generated on the server before mail, available as `[_dx_reference]` in the mail
  and shown on the page only after CF7 reports `mail_sent`.
* Mail: sent from the site address (Mail tab → From) with `Reply-To` set to the visitor;
  Mail (2) is off. The From address is fixed when the form is created — after moving to the
  live domain, re-run `wp driveo cf7` or edit the Mail tab.
* Storage: CF7 does not keep submissions. Flamingo is not installed.
* **Email on XAMPP:** PHP has no mail server locally, so CF7 reports "mail failed" and the page
  shows the failure message. For real delivery add to `wp-config.php`:

  ```php
  define( 'DRIVEO_SMTP_HOST', 'smtp.example.com' );
  define( 'DRIVEO_SMTP_PORT', 587 );
  define( 'DRIVEO_SMTP_SECURE', 'tls' );
  define( 'DRIVEO_SMTP_USER', 'user' );
  define( 'DRIVEO_SMTP_PASS', 'secret' );
  define( 'DRIVEO_SMTP_FROM', 'bookings@example.com' );
  ```

Business rules that refer to option values live in `inc/quote-form.php`: `DRIVEO_HOURLY`
("Hourly hire") and the `driveo_vehicle_limits` filter (Business Van 7/8; everything else
4/3). An unknown vehicle falls back to the stricter default limits. After renaming an
option in CF7, run `wp driveo check`.

## Production migration

URLs are stored absolutely. Elementor stores them JSON-escaped (`http:\/\/…`) in
`_elementor_data`, which `wp search-replace` alone does not match, so both commands are needed
(dry-run first, after a full database + files backup):

```bash
wp search-replace 'http://localhost/driveoexclusive' 'https://example.com' --all-tables-with-prefix --precise --report-changed-only --dry-run
wp search-replace 'http://localhost/driveoexclusive' 'https://example.com' --all-tables-with-prefix --precise --report-changed-only
wp elementor replace-urls 'http://localhost/driveoexclusive' 'https://example.com'
wp elementor flush-css
wp cache flush
```

Then: choose pretty permalinks (Settings → Permalinks → Save), set the CF7 Mail tab
From/To for the live domain, add `DRIVEO_SMTP_*` to `wp-config.php`, and send a real test
quote. Never deploy a `wp-content/mu-plugins` QA mail interceptor.

## Accessibility and motion

* Skip link → `#main`, visible focus rings, `aria-expanded` menu (Escape closes, focus returns).
* The hero video is attached only when `prefers-reduced-motion` is not set; otherwise the
  poster shows. A pause/play button is always available.
* Parallax and fleet tilt run only for a fine, hover-capable pointer and never with
  reduced motion; the city grid's 3D tilt and the form tilt are removed with reduced motion.
* Form: real labels, steppers are native number inputs with labelled +/- buttons,
  field errors linked with `aria-describedby`, status and errors in live regions.
